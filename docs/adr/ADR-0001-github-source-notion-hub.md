# ADR-0001: Use GitHub as source of truth; Notion as project hub
*Status:* Accepted
*Date:* 2025-10-28

## Context
We need a clear home for code, docs, and decisions.

## Decision
- GitHub repo stores code, schemas, exports, and versioned strategy docs.
- Notion hosts the project hub: status, links to commits/releases, task list, and ADR index.

## Consequences
- One URL to point AI assistants to (commit/tag).
- Notion remains human-friendly; GitHub remains canonical for versions.
