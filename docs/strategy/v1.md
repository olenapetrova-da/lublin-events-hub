# Strategy v1 — Minimal Working Flow

**Goal:** daily-updated DB of Lublin events with minimal ops cost.

1) **Workers** scrape sources and normalize fields: Title, Date, Time, Venue, Category, Link, Payment, Source, End Date.
2) **Google Sheets** receives `raw_events` then `events` after dedupe & mapping (Apps Script).
3) **Taxonomy** lives in Sheets: `taxonomy_map`, `taxonomy_alias`, `taxonomy_unmapped` log.
4) **Make** only triggers Workers (cron/manual) and writes rows. No heavy parsing in Make.
5) **Releases**: tag when strategy changes (v2, v3…) and freeze with a GitHub Release.
